# roboprojetoCC
Robo que pulveriza plantas que estão doentes

Esse robo tem como objetivo pulverizar as plantas que estão doentes, ele será controlado por meio de ESP32 e efetuará a pulverização através de um camera do próprio ESP.

#Instruções de Instalação

Para uso do Machine Learning, precisará efetuar a instalação dos documentos de projetorobo.py, modelo_planta.keras e dataset.rar
Poderá subir todos eles em Python para uso do projeto.

Já para o robo, poderá baixar as informações relacionadas ao controle (todos arquivos .ino).
